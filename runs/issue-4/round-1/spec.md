## 1. Purpose and Scope
### In-scope
- Support pipe-separated link text syntax `[[Target Page|what the reader sees]]` in the `wikilinks` extension.
- Preserve existing URL building rules (`base_url`, `end_url`, `html_class`, `build_url`) for the target part of the wikilink.
- Maintain backward compatibility so that plain `[[Main Page]]` continues to work exactly as currently implemented.

### Out-of-scope
- Changes to any other extensions.
- Changes to markdown features outside of `wikilinks`.

### Scope unknown
- Handling of escaped pipes or malformed syntax such as `[[Page|text|extra]]` or `[[|text]]`.

## 3. Functional Requirements
| ID | Requirement (EARS) | Tag | Source / Link | Priority | Readiness |
|---|---|---|---|---|---|
| FR-001 | When processing Markdown input containing `[[Target Page|link text]]` with the `wikilinks` extension enabled, the system shall render an HTML anchor tag where the href attribute is built from the target part using existing `base_url`, `end_url`, `html_class`, and `build_url` handling, and the link content is the specified link text. | [S] | SRC-1.2, SRC-1.4, SRC-1.5 | Must | Ready |
| FR-002 | When processing Markdown input containing plain `[[Main Page]]` with the `wikilinks` extension enabled, the system shall render an HTML anchor tag continuing to work exactly as currently implemented. | [S] | SRC-1.5 | Must | Ready |
| FR-003 | When processing Markdown input containing `[[Main Page|the home page]]` with the `wikilinks` extension enabled, the system shall output `<p>See <a class="wikilink" href="/Main_Page/">the home page</a>.</p>`. | [S] | SRC-1.3 | Must | Ready |

### FR-001 acceptance criteria:
- AC-FR-001-1: Given markdown input `See [[Main Page|the home page]].` with extensions `["wikilinks"]`, when parsed, then the output is `<p>See <a class="wikilink" href="/Main_Page/">the home page</a>.</p>`.

### FR-002 acceptance criteria:
- AC-FR-002-1: Given markdown input `See [[Main Page]].` with extensions `["wikilinks"]`, when parsed, then the output contains `<a class="wikilink" href="/Main_Page/">Main Page</a>` (or the default text generated by the current implementation).

### FR-003 acceptance criteria:
- AC-FR-003-1: Given markdown input `See [[Main Page|the home page]].` with extensions `["wikilinks"]`, when parsed, then the output matches exactly `<p>See <a class="wikilink" href="/Main_Page/">the home page</a>.</p>`.

## Appendix A. Source Register

What I'd like: markdown.markdown("See [[Main Page|the home page]].", extensions=["wikilinks"]) # <p>See <a class="wikilink" href="/Main_Page/">the home page</a>.</p>
- SRC-1.4: So the part before `|` builds the URL exactly like it does today (same `base_url`, `end_url`, `html_class` and `build_url` handling) and the part after `|` is the text of the link.
- SRC-1.5: Plain `[[Main Page]]` should keep working exactly as now.

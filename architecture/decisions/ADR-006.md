# ADR-006: Gemini free tier, with a different model for the reviewer

**Status:** Accepted
**Date:** 2026-11-21
**Decision area:** D6, models

## Context

The available credential is a Gemini API key on the free tier. The models that can be used for free are Gemini 3.8 Flash, 3.6 Flash, 3.5 Flash-Lite and 4 Hydrogen, per the Gemini API pricing page, read 2026-11-21. Pro models are not free.

The free tier has per-model limits on requests per minute, tokens per minute and requests per day. These limits are not published on the public docs page.

A test call on 2026-11-21 showed:

- 3.5 Flash-Lite returned a correct function call.
- 3.8 Flash and 4 Hydrogen both returned `503 UNAVAILABLE` ("high demand").

Free-tier prompts may be used by Google to improve its products. The repository is public, so nothing private is sent.

## Decision

| Role | Primary model | Fallback chain on 503/429 | Why |
| --- | --- | --- | --- |
| Spec, Designer, Implementer, Tester | `gemini-3.8-flash` | `gemini-3.6-flash` → `gemini-3.5-flash-lite` | Strongest free Flash model, good at tool use and long context |
| Reviewer | `gemini-4-hydrogen` | `gemini-3.6-flash` → `gemini-3.5-flash-lite` | A different model family from the builders, so it does not share their blind spots |

The model id actually used is written into every artifact header and into `state.json`.

If the reviewer falls back to a model the builders also used in that run, `review.md` says so. The run is flagged in `results.csv` as reduced independence.

Model ids are pinned to versions, never `-latest` aliases. An alias can change target during the experiment, and the results would then compare two different models without anyone noticing.

## Alternatives considered

- **One model for every role.** Simpler and uses one rate-limit pool. Rejected because the reviewer would share the implementer's tendencies (ADR-008). Kept as the "same model" variant of the D8 experiment.
- **Claude (Haiku/Sonnet) through an Anthropic API key.** Stronger and better known from A2, but it needs a paid key, and the free Gemini key was available.
- **Flash-Lite everywhere.** Most reliable at the moment and cheapest, but weakest at multi-file code changes.
- **Pro models for the reviewer.** Not free.

## Consequences

- Because of the 503s, the client must retry with backoff and then fall back (ADR-009). A run may use different models on different days, and the artifact headers record this.
- Limits are per Google Cloud project, not per key, so experiment runs must be spaced out. They cannot all run in parallel.
- Hydrogen's behaviour as a reviewer is untested. The seeded-PR experiment (D8) measures it before it is trusted.
- Token use is counted from `usageMetadata` on every response and reported per run, as the rules require.

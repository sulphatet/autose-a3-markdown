# ADR-006: Gemini Flash-Lite models, with a different version for the reviewer

**Status:** Accepted
**Date:** 2026-11-21
**Decision area:** D6, models

## Context

The available credential is a Gemini API key on the free tier.

The aim of the course is a workflow whose design can be explained, not the best possible patches ("as long as it works"). Model quality is therefore a lower priority than reliability and simplicity.

Test calls on 2026-11-21, each one request with a single `read_file` tool:

| Model | Result |
| --- | --- |
| `gemini-3.8-flash` | `503 UNAVAILABLE` three times ("high demand", once "deadline expired" after about 2 min) |
| `gemini-4-hydrogen` | `503 UNAVAILABLE` |
| `gemini-3.5-flash-lite` | 200, correct function call |
| `gemini-3.1-flash-lite` | 200, correct function call |

Free-tier prompts may be used by Google to improve its products. The repository is public, so nothing private is sent.

## Decision

| Role | Model | Why |
| --- | --- | --- |
| Spec, Designer, Implementer, Tester | `gemini-3.5-flash-lite` | Answered reliably and made correct tool calls. Fast and free. |
| Reviewer | `gemini-3.1-flash-lite` | Also reliable. A different model version from the builders, at no extra cost, so the reviewer is not the same model checking its own output. |

Model ids are pinned to versions, never `-latest` aliases. An alias can change target during the experiment.

The model id that actually answered is written into every artifact header and `state.json`.

The client retries on 503/429 with a short backoff (ADR-009). There is no fallback to a different model, so a run always uses the models above, and the results are about these two models only.

## Alternatives considered

- **`gemini-3.8-flash` for builders, `gemini-4-hydrogen` for the reviewer.** The stronger free models, and the first version of this ADR before it was merged. Rejected after the test calls above: both were unavailable, and a fallback chain would have mixed models within one experiment.
- **One Lite model for every role.** Simplest. Rejected because a second Lite version costs nothing and removes the "same model reviews itself" problem (ADR-008). Kept as the "same model" variant in the reviewer experiment.
- **Claude (Haiku) through an Anthropic API key.** Used in A2, but it needs a paid key.

## Consequences

- Lite models are weaker at multi-file changes. More runs are expected to stop at stage 3 or 4 within budget. That is acceptable, and it is reported honestly in the results.
- `3.1` and `3.5` Flash-Lite come from the same family, so they may share blind spots. Independence rests mainly on separate context, prompt, permissions and identity (ADR-008), not on the model.
- Token use is counted from `usageMetadata` on every response and reported per run.
